# BK-KMS-SDK GO版本

提供 Go 语言的 BK-KMS SDK。

## Features

- 解密信封: 支持凭证消费运行时解密基础功能

## Installation

```bash
go get github.com/TencentBlueKing/bk-kms-sdk/go
```
